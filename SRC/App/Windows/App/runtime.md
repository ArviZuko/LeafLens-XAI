# Portable Windows runtime

Download [LeafLens-Windows-runtime.zip](https://github.com/ArviZuko/LeafLens-XAI/releases/download/project-assets-v1/LeafLens-Windows-runtime.zip) and extract it into this directory. The resulting `_internal` folder must sit beside `app.exe`.

The archive preserves the complete supplied runtime, including its bundled assets and dependencies. The directory is distributed as a Release asset because some files exceed GitHub's regular Git file limit. Alternatively, use the [Windows installer](../Installer/installer.md).
